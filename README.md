# KUG Coimbatore
Official website for the Kotlin User Group Coimbatore.

**Organizer:** Dhanu Shree V G  
**Co-Organizer:** Sanjay S

## Tech Stack
- React 18 + Vite
- WebGL particle hero (Canvas 2D fallback)
- GSAP + ScrollTrigger + SplitText
- Lenis smooth scroll
- Tailwind CSS (flat instrument UI, no liquid glass)

## Run Locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
